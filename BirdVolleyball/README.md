# 🐦 Bird Volleyball - Windows Forms Edition

Аркадный волейбол, где каждый может погрузиться в атмосферу спорта и веселья!

## 🎮 О игре

Bird Volleyball — динамичная 2D-аркада с упрощённой механикой волейбола. Две птички разделены сеткой, а над полем висит мяч, готовый начать раунд. Ваша задача — правильно оценить траекторию, выбрать тип приёма и не дать мячу коснуться своей площадки.

## ⚡ Ключевые механики

| Механика | Описание |
|----------|----------|
| ⏱️ Обратный отсчёт | Мяч появляется строго сначала над вашей птицей, после на стороне проигравшего |
| 🤲 Нижний приём | Мягкий, контролируемый пас. Перебрасывает мяч на сторону соперника с низкой траекторией |
| 💥 Вертикальный смэш | Резкий взлёт + мощный удар сверху. Высокая скорость, сложный для приёма, но требует точного тайминга |
| ☝️ Правило одного касания | На стороне может быть только один контакт. Второе касание или падение на свою половину = очко противнику |

## 🕹️ Управление

| Действие | Клавиша (по умолчанию) |
|----------|------------------------|
| ← Движение влево | A / левая стрелочка |
| → Движение вправо | D / правая стрелочка |
| 🤲 Нижний приём | Пробел |
| 💥 Удар сверху | Shift |
| 🔄 Сброс раунда | R |

## 📥 Быстрый старт

### Требования
- Windows 10/11
- .NET 6.0 SDK или выше

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/bird-volleyball.git
cd bird-volleyball/BirdVolleyball

# 2. Соберите проект
dotnet build

# 3. Запустите игру
dotnet run
```

### Сборка под Windows

```bash
# Опубликовать как standalone приложение
dotnet publish -c Release -r win-x64 --self-contained true
```

Исполняемый файл будет находиться в папке `bin/Release/net6.0-windows/win-x64/publish/`

## 📖 Правила игры

1. Раунд начинается с появления мяча над левой птицей (игрок)
2. Идёт обратный отсчёт 3 секунды
3. Мяч падает. Игрок выбирает: нижний приём или удар
4. На каждой стороне допускается ровно одно касание
5. Если мяч касается земли на стороне птицы А → очко получает птица Б
6. Игра идёт до 7 очков (разница минимум в 2 очка)
7. После каждого розыгрыша мяч снова появляется над проигравшей стороной

## 🔧 Настройка

Измените параметры в файле `GameSettings.cs`:

```csharp
public class GameSettings
{
    // Управление
    public Keys MoveLeft = Keys.A;
    public Keys MoveRight = Keys.D;
    public Keys LowPass = Keys.Space;
    public Keys Smash = Keys.ShiftKey;
    
    // Настройки игры
    public int PointsToWin = 7;
    public float Gravity = 0.5f;
    public float PlayerSpeed = 8f;
    // ... и другие параметры
}
```
