# 🐦 Bird Volleyball
> Аркадный волейбол, где каждый может погрузиться в атмосферу спорта и веселья!

---

## 🎮 О игре
`Bird Volleyball` — динамичная 2D-аркада с упрощённоц механикой волейбола. Две птички разделены сеткой, а над полем висит мяч, готовый начать раунд. Ваша задача — правильно оценить траекторию, выбрать тип приёма и не дать мячу коснуться своей площадки.

---

## ⚡ Ключевые механики
| Механика | Описание |
|:---|:---|
| ⏱️ Обратный отсчёт | Мяч появляется строго сначала над вашей птицей, после на стороне проигравшего. |
| 🤲 Нижний приём | Мягкий, контролируемый пас. Перебрасывает мяч на сторону соперника с низкой траекторией. |
| 💥 Вертикальный смэш | Резкий взлёт + мощный удар сверху. Высокая скорость, сложный для приёма, но требует точного тайминга. |
| ☝️ Правило одного касания | На стороне может быть только один контакт. Второе касание или падение на свою половину = очко противнику. |

## 🕹️ Управление
| Действие | Клавиша (по умолчанию) |
|:---|:---|
| <> Движение | `S / левая стрелочка` / ` R / правая стрелочка ` |
| 🤲 Нижний приём | `Пробел` / `ЛКМ` |
| 💥 Удар сверху | `Shift` / `ПКМ` |
| 🔄 Сброс раунда | `R` |

> 💡 Привязка клавиш вынесена в конфигурационный файл. Измените под себя в `Settings/Controls.json`.

## 📖 Правила игры
1. Раунд начинается с появления мяча над левой птицей.
2. Идёт обратный отсчёт `3` секунды.
3. Мяч падает. Игрок выбирает: `нижний приём` или `удар`.
4. На каждой стороне допускается **ровно одно касание**.
5. Если мяч касается земли на стороне птицы А → очко получает птица Б.
6. Игра идёт до `7` очков (разница минимум в 2 очка).
7. После каждого розыгрыша мяч снова появляется над проигравшей стороной.
